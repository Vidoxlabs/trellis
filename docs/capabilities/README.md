# Capabilities

- Folder purpose: holds `trellis` capability ledgers (`index.json`) for touched capabilities (`trellis` leads no capabilities and probes module repositories only, never `bloom` or `docs`).
- Hub timeline: cross-repo roadmap, capability index, and timeline rules live at [Vidoxlabs/docs timeline](https://github.com/Vidoxlabs/docs/blob/main/docs/timeline/README.md).
- Same-PR ledger rule: any PR changing capability status, claim, slices, contracts, tests, PRs, commits, or ADRs updates `index.json`, the owning spec, `docs/CHANGELOG.md`, and affected contract `Changes` sections together.
